Setup Instructions

                

                    

                        

                            
1. Install Python 3.10+

                            
Windows: Download from python.org, check Add python.exe to PATH

                            
python --version
pip --version

                            
Linux:

                            
sudo apt update
sudo apt install python3 python3-pip python3-venv git -y

                        

                        

                            
2. Install markitdown

                            
pip install -e "packages/markitdown[all]"

                        

                        

                            
3. Verify

                            
markitdown --version
